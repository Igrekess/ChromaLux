This documentation covers the developer interfaces that are actually present
in ChromaLux 0.6.5.

- [Native plug-in SDK](en/plugin-sdk.md)

ChromaLux 0.6.5 does not yet provide an HTTP/REST API, a standalone SDK
installed by the DMG, or a compatibility guarantee for a public third-party
ecosystem. The documents distinguish active contracts from internal interfaces
and known limitations.
